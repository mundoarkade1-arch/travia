# Configuração simples

1. Instale Node.js 18+.
2. Abra um terminal nesta pasta.
3. Execute `npm install` para instalar Tesseract.js e pdfjs-dist.
4. Execute `npm start`.
5. Acesse `http://localhost:4173`.

Para parar, pressione `Ctrl+C`. Na primeira execução do OCR, o idioma português pode ser baixado pelo Tesseract.js. No celular, o servidor precisa estar acessível na mesma rede; a versão de produção deverá fornecer um empacotamento Android/PWA.
